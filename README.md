# connor

A terminal text editor for working alongside a coding agent.

The agent runs in a separate terminal process and does most of the writing — it is not integrated, but the workflow feels like an agent plugin in a GUI editor: connor is where you read the code, review what changed, leave notes, and make your own edits. When no agent is running, it's simply a good everyday text editor.

It's easy to pick up: no modes, nothing to study, and keyboard and mouse workflows are both first-class. It ships as a single self-contained binary: copy it to a remote machine and it runs. It does a few things well — a feature can overlap a dedicated tool when having it inside the editor is the point, but connor never tries to become that tool.

Named for Sarah Connor of *Terminator* — the human the machine works alongside.
